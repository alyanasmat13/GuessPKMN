# Pokémon Quiz Game - Interactive Web Application

Developed a full-stack, responsive web application using React.js with TypeScript and Tailwind CSS, integrating RESTful API to create an interactive Pokémon identification game. Implemented strongly-typed asynchronous functions with async/await patterns to consume the PokeAPI, fetching data for all 1,025 Pokémon entities with dynamic content rendering and type-safe interfaces. Engineered a randomization algorithm for non-repetitive gameplay and built a real-time scoring system with persistent state management using React Hooks (useState, useEffect) with TypeScript generics. Applied mobile-first responsive design principles using Tailwind's utility-first CSS framework, ensuring cross-browser compatibility and optimal user experience across all devices.
